Pangea – Interface LLM modérée

Pipeline :

  1. Votre prompt passe d’abord dans le prompt classifier (Groq)
  2. S’il est accepté, un LLM local (Ollama) génère 10 réponses
  3. Les 10 réponses passent dans le modérateur Mistral
  4. On sélectionne les 2 réponses les plus sûres et on vous les affiche
Posez une question ci-dessous. Votre prompt et les 2 réponses sélectionnées s'afficheront ici, comme dans une interface de chat.
